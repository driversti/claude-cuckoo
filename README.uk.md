# Cuckoo 🐦

[🇬🇧 English](README.md) · 🇺🇦 Українська

**Надійний персональний календар для Claude Code.** Постав нагадування на майбутню дату (за бажанням
і час), і Cuckoo поверне його наступного разу, коли ти відкриєш сесію Claude Code на цю дату або
пізніше — наче зозуля з годинника, що вискакує у потрібну мить. Це *файл-нагадайка* (tickler file)
для Claude Code.

Нагадування зберігаються у звичайних файлах, тож переживають перезапуски. Коли нічого не настало,
Cuckoo коштує тобі практично **нуль токенів контексту**.

## Як це працює

- **Хук SessionStart** запускає крихітну команду (`cuckoo check`) на старті кожної сесії. Вона
  читає невеликий індекс і друкує нагадування, яким настав час, — або мовчить.
- Команда **`/cuckoo:schedule`** дозволяє додавати, переглядати, завершувати та переносити
  нагадування.
- Нагадування зберігаються у двох рівнях:
  - 🌍 **Глобальний** — `~/.claude/cuckoo/` — особистий, працює у будь-якому проєкті.
  - 📂 **Проєктний** — `<твій-репозиторій>/.cuckoo/` — прив'язаний до конкретного репозиторію (за
    замовчуванням ігнорується git).

> **Спрацьовує від сесії, а не як будильник.** Cuckoo не може надіслати пуш на телефон і не є
> спливаючим вікном у терміналі. На старті сесії хук передає нагадування, яким настав час, до Claude,
> а той озвучує їх у **першій відповіді щойно ти надішлеш повідомлення** — тож новісінька сесія, на
> яку ти просто дивишся (нічого не вводячи), нічого не покаже, доки ти не напишеш. Час доби — це
> *найраніший* момент появи, а не сповіщення в реальному часі. (Інтеграцію з календарем/пушами
> заплановано.)

## Встановлення

```
/plugin marketplace add driversti/claude-cuckoo
/plugin install cuckoo@cuckoo
```

Потім перезапусти Claude Code (або виконай `/reload-plugins`).

## Використання

```
/cuckoo:schedule add tomorrow "email the tax form"
/cuckoo:schedule add 2026-07-01 09:00 "quarterly review"
/cuckoo:schedule add next friday "call the dentist" --global
/cuckoo:schedule list
/cuckoo:schedule done call-the-dentist
/cuckoo:schedule reschedule quarterly-review "next monday 8am"
```

- Дати визначаються у твоєму локальному часовому поясі; працює природна мова ("tomorrow", "next
  friday 9am", "in 3 days").
- Рівень за замовчуванням — **глобальний**. Усередині git-репозиторію, якщо не передати флаг, Cuckoo
  запитає, прив'язати нагадування до репо (**проєктний**) чи лишити **глобальним** — передай
  `--global`/`--project`, щоб пропустити запитання.

Коли нагадуванню настав час, твоя наступна сесія відкривається нотаткою на кшталт:

```
⏰ CUCKOO — scheduled task(s) due
  • [global] call-the-dentist (due 2026-06-20) -> ~/.claude/cuckoo/call-the-dentist.md
```

Claude читає завдання, піднімає його, пропонує діяти за ним, а потім питає, чи позначити його
завершеним, чи перенести.

## Чому майже нуль токенів

Хук SessionStart виконується у твоєму шелі, а не в моделі. Він читає лише крихітний індекс
(`дата · статус · slug`) і нічого не друкує, доки нічому не настав час. Повний текст нагадування
лежить у власному файлі й читається лише в день спрацювання. Простоювана сесія платить лише за
однорядковий опис команди.

## Дані та приватність

- Усе — це локальні файли. Жодної мережі, жодної телеметрії.
- Проєктні нагадування лежать у `<репозиторій>/.cuckoo/`, який постачається з `.gitignore` (`*`), тож
  твої особисті нагадування ніколи не потрапляють у коміт.

## Розробка

```bash
# Завантажити плагін локально без встановлення:
claude --plugin-dir /path/to/claude-cuckoo
# Після правок:
/reload-plugins
# Запустити набір тестів (без залежностей):
bash tests/run.sh
```

Структура даних і CLI:

```
~/.claude/cuckoo/            # глобальний рівень
├── _index.md                #   DUE  STATUS  SLUG   (крихітний; хук читає лише його)
└── <slug>.md                #   тіло нагадування (читається лише коли настав час)
<repo>/.cuckoo/              # проєктний рівень (та сама структура + .gitignore '*')

bin/cuckoo  check | list | dir | add | remove | done | reschedule
```

## Дорожня карта

- **Двостороння синхронізація з Google Calendar** — справжні пуш-сповіщення на пристрій.
- **Точний таймер у межах сесії** — спрацьовування у точну хвилину, поки сесія відкрита.
- **Повторювані** нагадування, **відкладання** (snooze).
